# Yuima_AI-Agent

## 📋 Описание проекта
Yuima — desktop AI-агент на Go. Управляет задачами, ставит напоминания, ищет в интернете, работает с локальной LLM

[![Go Badge](https://shields.io)](https://go.dev)
[![MIT License Badge](https://shields.io)](https://opensource.org)

## 🛠 Основные функции
- Общаться с ЛЛМ(локальной или облачной)
- Использовать 8 инструментов:
  1. 5 инструментов работы с задачами
  2. 2 инструмента для работы с напоминаниями
  3. 1 инструмент для работы с погодой
  4. 1 инструмент для поиска информации в интернете
- Автоматическое сжатие контекста
- Фоновая очистка выполненных задач
- Фоновый сервис напоминаний с системными уведомлениями
- SQLite + in-memory хранилища
- Защита от promt-injection

internal/

## 🚀 Установка и запуск

### Требования
- Go 1.27+
- C-компилятор
- Установка SearxNG(для web_search)

## Установка
1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/Alladinchik7/Yuima_AI-Agent
   ```
2. Перейдите в директорию проекта
   ```bash
   cd Yuima\cmd\desktop
   ```
3. Запустите программу
   ```bash
   go run main.go
   или
   go run .
   ```

## ВАЖНО
- Не забудьте создать .env(используйте .env.example как пример)

### Примеры
1. ```text
   Пользователь: Добавь три задачи: купить хлеб, сходить в кино, написать API
   Агент: [вызывает add_todo × 3] Готово, добавил 3 задачи.
   ```
2. ```text
   Пользователь: Напомни завтра в 12 позвонить маме
   Агент: [вызывает set_reminder] Поставил напоминание на 19.10.2026 12:00.
   ```
