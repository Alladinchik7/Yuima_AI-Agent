Телеграм-бот-агент:
1. Отвечает на сообщения
2. Ведёт список дел
3. Ставит напоминания
4. Ищет информацию в интернете

1. Какие  задачи  пользователь решает в ручную?
  1.1 Ведет список дел
    1.1.1 Добавление, удаление, редактирование дел
    1.1.2 Отметка дел как выполненных
    1.1.3 Выстановление приоритетов
  1.2 Ставит напоминания
  1.3 Ищет информацию в интернете
    1.3.1 Ищет достоверную информацию
    1.3.2 Сравнивает результаты
2. Что агент точно не должен делать?
  2.1 Удалять напоминания без подтверждения
  2.2 Отправлять сообщения третьим лицам
  2.3 Тратить больше N токенов на один запрос
  2.4 Отвечать на сообщения без контекста
3. Что делать если агент не справился?
  3.1 Честно сказать, что не может выполнить задачу
  3.2 Попробовать выполнить задачу в другом формате

Про фоновый процесс на ПК при выключенном приложении
Это отдельная большая задача, не для хакатона. Разберу честно.

Что нужно для работы при выключенном приложении:

Демон/сервис — программа, которая работает в фоне без UI.

Автозапуск — регистрация в системе: systemd (Linux), Task Scheduler (Windows), launchd (macOS).

Хранилище, которое переживает перезапуск — то есть БД на диске, не in-memory map.

Канал доставки уведомлений без UI — на Linux notify-send, на Windows Toast API, на macOS osascript.
